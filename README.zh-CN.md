# ExileKit

**语言：** [English](README.md) | 简体中文

ExileKit 是一个轻量级原生 Windows POE 工具启动器。

## 使用方法

1. 在 **Releases** 下载最新版 `ExileKit.exe`。
2. 直接运行 `ExileKit.exe`，无需安装。
3. 进入 **POE** 或 **POE2** 页面。
4. 点击工具即可启动。
5. 如果没有检测到工具：
   - 点击 **官网** 前往官方下载
   - 或选择 **定位**，手动指定已有 `.exe`
6. 常用工具可以添加或固定到 **Home**。
7. 在 Home 点击 **+** 可以添加自己的：
   - 网站
   - EXE
   - LNK 快捷方式
8. 右键工具可以：
   - 打开
   - 添加 / 固定到 Home
   - 定位程序
   - 打开官网
9. 点击窗口右上角 `X` 会隐藏到系统托盘，不会退出。
10. 通过托盘图标可以重新打开 ExileKit 或彻底退出。

## 更新

ExileKit 会自动检查稳定版本更新。

也可以在 **Settings** 中手动检查更新。
