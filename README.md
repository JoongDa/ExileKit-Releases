# ExileKit

**Language:** English | [简体中文](README.zh-CN.md)

ExileKit is a lightweight native Windows launcher for Path of Exile tools.

## How to Use

1. Download the latest `ExileKit.exe` from **Releases**.
2. Run `ExileKit.exe`. No installation is required.
3. Open the **POE** or **POE2** page.
4. Click a tool to launch it.
5. If the tool is not detected:
   - Open its **Official Website**
   - Or choose **Locate** to select the existing `.exe`
6. Tools you open can be added to **Home** for quick access.
7. Use **+** on Home to add your own:
   - Website
   - EXE
   - LNK shortcut
8. Right-click a tool for:
   - Open
   - Add / Pin to Home
   - Locate
   - Official Website
9. Click `X` to hide ExileKit to the system tray.
10. Use the tray icon to reopen ExileKit or fully exit.

## Updates

ExileKit automatically checks for stable updates.

You can also manually check for updates in **Settings**.

## Download

Go to **Releases** and download the latest `ExileKit.exe`.

- Windows x64
- Single executable
- No installation required
